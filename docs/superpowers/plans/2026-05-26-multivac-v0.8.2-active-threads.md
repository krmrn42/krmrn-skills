# Multivac v0.8.2 — active threads inline under project groups — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.8.2 of `@krmrn42/multivac` — discover currently-running `claude` processes, correlate each to a chat (when its JSONL is indexed) and to a tmux pane (when `$TMUX` is set), inject the results INSIDE each project's group in the picker, and add `r` (force-refresh) + `Ctrl-W` on project rows.

**Architecture:** A new `ActiveThreadSource` (Claude-only, hard-coded — multi-source is post-v0.8.2 per spec §D14) lives at `packages/multivac/src/sources/claude/active.ts`. It composes three OS-abstraction primitives in `packages/multivac/src/sources/claude/proc.ts` (Linux `/proc` + macOS `lsof/ps`) and one tmux primitive in `packages/multivac/src/sources/claude/tmux-panes.ts`. A new `ActiveThreadRow` joins the `Selectable` union; `buildProjectGroups()` accepts an `activeThreads: ActiveThreadRow[]` argument and injects them into each project's group — **replacing** the corresponding chat row when mapped (per the spec §D5 first option, chosen here for visual clarity), **prepending** above the chat list when unmapped, or producing a synthetic project header when the thread's cwd doesn't match any indexed project. A new `useActiveThreads` hook drives a 4-second `setInterval` rescan + `r` force-refresh; the resulting threads array feeds `useSearch`, which calls `buildProjectGroups` whenever either input changes.

**Tech Stack:** TypeScript 5.5, `node:sqlite` (Node 22.5+), `node:fs/promises`, `node:child_process`, Ink 5 + React 18, esbuild, `node:test` + `ink-testing-library`.

**Spec:** [`docs/superpowers/specs/2026-05-24-multivac-dashboard-design.md`](../specs/2026-05-24-multivac-dashboard-design.md) — see D1 (v0.8.2 layout mockup), D4 (`ActiveThreadRow` shape + selectability), D5 (process discovery, tmux correlation, project-group placement, refresh strategy), D7 (active-thread preview pane), D10 (`r`/`Ctrl-W` keybindings), D11 (🟢/🟡 markers + ASCII fallbacks), D14 (v0.8.2 row in the phasing table).

```typescript
import * as fs from "node:fs/promises";
import * as childProc from "node:child_process";

/** A captured subprocess result. `status === 0` ⇒ stdout is meaningful. */
export interface CaptureResult {
  stdout: string;
  status: number;
}

/** Default spawnCapture wraps childProc.spawnSync with shell-free invocation. */
function defaultSpawnCapture(cmd: string, args: string[]): Promise<CaptureResult> {
  return new Promise((resolve) => {
    const res = childProc.spawnSync(cmd, args, { encoding: "utf8" });
    if (res.error) {
      resolve({ stdout: "", status: 127 });
      return;
    }
    resolve({ stdout: res.stdout ?? "", status: res.status ?? 1 });
  });
}

type SpawnCaptureFn = (cmd: string, args: string[]) => Promise<CaptureResult>;
let spawnCapture: SpawnCaptureFn = defaultSpawnCapture;

/**
 * Override the subprocess runner — tests only. Pass `null` to restore the
 * default. Production code never imports this; the export is named with a
 * double-underscore prefix to make grep easy.
 */
export function __setSpawnCaptureForTests(fn: SpawnCaptureFn | null): void {
  spawnCapture = fn ?? defaultSpawnCapture;
}

/** Extract integer pids from one-per-line pgrep output. */
export function parsePgrepOutput(stdout: string): number[] {
  const out: number[] = [];
  for (const line of stdout.split("\n")) {
    const trimmed = line.trim();
    if (!trimmed) continue;
    const n = Number(trimmed);
    if (Number.isInteger(n) && n > 0) out.push(n);
  }
  return out;
}

/**
 * Parse `lsof -F n` output. We care only about the LAST `n`-prefixed line,
 * which is the cwd path. Returns null when absent.
 */
export function parseLsofCwdOutput(stdout: string): string | null {
  let last: string | null = null;
  for (const line of stdout.split("\n")) {
    if (line.startsWith("n")) last = line.slice(1);
  }
  return last && last.length > 0 ? last : null;
}

/**
 * Parse field 4 (ppid) from /proc/PID/stat. The kernel encodes `comm` (field 2)
 * inside parentheses, and `comm` may contain spaces and even parens. We therefore
 * locate the LAST `)` in the string and read the field after it.
 *
 * stat format reference: man 5 proc
 *   pid (comm) state ppid pgrp session …
 */
export function parseLinuxStatPpid(stdout: string): number | null {
  const lastParen = stdout.lastIndexOf(")");
  if (lastParen < 0) return null;
  const tail = stdout.slice(lastParen + 1).trim();
  const parts = tail.split(/\s+/);
  // Index 0 of `parts` is `state`; index 1 is `ppid`.
  if (parts.length < 2) return null;
  const ppid = Number(parts[1]);
  return Number.isInteger(ppid) && ppid > 0 ? ppid : null;
}

/** Returns the PIDs of running `claude` processes, or [] on failure. */
export async function listClaudePids(): Promise<number[]> {
  const result = await spawnCapture("pgrep", ["-f", "^claude($| )"]);
  if (result.status !== 0) return [];
  return parsePgrepOutput(result.stdout);
}

/**
 * Return the cwd of a process, or null on failure (process gone, permission
 * denied, unsupported platform path).
 */
export async function readProcessCwd(pid: number): Promise<string | null> {
  if (process.platform === "linux") {
    try {
      return await fs.readlink(`/proc/${pid}/cwd`);
    } catch {
      return null;
    }
  }
  // macOS (and any non-Linux POSIX): lsof -p PID -d cwd -F n
  const result = await spawnCapture("lsof", ["-p", String(pid), "-d", "cwd", "-F", "n"]);
  if (result.status !== 0) return null;
  return parseLsofCwdOutput(result.stdout);
}

/** Return the parent PID, or null on failure. */
export async function readProcessParent(pid: number): Promise<number | null> {
  if (process.platform === "linux") {
    try {
      const stat = await fs.readFile(`/proc/${pid}/stat`, "utf8");
      return parseLinuxStatPpid(stat);
    } catch {
      return null;
    }
  }
  // macOS: ps -o ppid= PID  (trailing `=` suppresses the header line)
  const result = await spawnCapture("ps", ["-o", "ppid=", "-p", String(pid)]);
  if (result.status !== 0) return null;
  const trimmed = result.stdout.trim();
  const ppid = Number(trimmed);
  return Number.isInteger(ppid) && ppid > 0 ? ppid : null;
}
```

```typescript
import * as childProc from "node:child_process";
import { readProcessParent } from "./proc.js";

const MAX_ANCESTOR_LEVELS = 5;

const FORMAT_STRING =
  "#{pane_id}\t#{pane_pid}\t#{pane_current_command}\t#{window_id}\t#{window_index}\t#{window_name}";

export interface TmuxPane {
  paneId: string;
  pid: number;
  currentCommand: string;
  windowId: string;
  windowIndex: number;
  windowName: string;
}

export interface CaptureResult {
  stdout: string;
  status: number;
}

type SpawnCaptureFn = (cmd: string, args: string[]) => Promise<CaptureResult>;

function defaultSpawnCapture(cmd: string, args: string[]): Promise<CaptureResult> {
  return new Promise((resolve) => {
    const res = childProc.spawnSync(cmd, args, { encoding: "utf8" });
    if (res.error) {
      resolve({ stdout: "", status: 127 });
      return;
    }
    resolve({ stdout: res.stdout ?? "", status: res.status ?? 1 });
  });
}

let spawnCapture: SpawnCaptureFn = defaultSpawnCapture;

/** Test-only override. */
export function __setSpawnCaptureForTmuxTests(fn: SpawnCaptureFn | null): void {
  spawnCapture = fn ?? defaultSpawnCapture;
}

/** Parse the tab-separated tmux output into structured panes. Malformed lines are skipped. */
export function parseTmuxPanes(stdout: string): TmuxPane[] {
  const out: TmuxPane[] = [];
  for (const line of stdout.split("\n")) {
    if (!line) continue;
    const parts = line.split("\t");
    if (parts.length !== 6) continue;
    const pid = Number(parts[1]);
    const windowIndex = Number(parts[4]);
    if (!Number.isInteger(pid) || !Number.isInteger(windowIndex)) continue;
    out.push({
      paneId: parts[0],
      pid,
      currentCommand: parts[2],
      windowId: parts[3],
      windowIndex,
      windowName: parts[5],
    });
  }
  return out;
}

/** Returns all tmux panes (across sessions/windows), or [] if tmux is absent or fails. */
export async function listTmuxPanes(): Promise<TmuxPane[]> {
  const result = await spawnCapture("tmux", ["list-panes", "-a", "-F", FORMAT_STRING]);
  if (result.status !== 0) return [];
  return parseTmuxPanes(result.stdout);
}

/**
 * Match `pid` (and up to 5 ancestor PIDs) against the pane PID set. Returns
 * the first matching pane, or null. The 5-level cap covers the realistic
 * shell → claude → child chain; deeper chains imply nested tmux or screen and
 * graceful no-match is acceptable (spec §D5).
 */
export async function correlatePidToTmux(pid: number, panes: TmuxPane[]): Promise<TmuxPane | null> {
  if (panes.length === 0) return null;
  const byPid = new Map<number, TmuxPane>();
  for (const p of panes) byPid.set(p.pid, p);
  let cur: number | null = pid;
  for (let depth = 0; depth < MAX_ANCESTOR_LEVELS && cur !== null; depth++) {
    const match = byPid.get(cur);
    if (match) return match;
    cur = await readProcessParent(cur);
  }
  return null;
}
```

The orchestrator. Pipeline:

1. `listClaudePids()`
2. For each pid: `readProcessCwd(pid)` → URL-encode-style transform to projects-dir name (`cwd.replace(/\//g, "-")`)
3. List `.jsonl` files in that directory by mtime desc; the newest is the live session candidate. Its filename (sans `.jsonl`) is the `sessionId`.
4. Classify status by mtime age: `< 60_000 ms` → `live`, `< 30 * 60_000 ms` → `idle`, else drop.
5. Look up `conversation_id` in the DB: if present in `messages`, the thread is **mapped** — pull `title`, `msgCount`, `gitBranch`, `recapText` to mirror onto the row.
6. Run `listTmuxPanes()` once. For each row, `correlatePidToTmux(pid, panes)` to attach `tmuxPaneId` + `tmuxWindow`.

The function is `async` and returns `Promise<ActiveThreadRow[]>`.

```typescript
import * as fs from "node:fs/promises";
import * as path from "node:path";
import type { DatabaseSync } from "node:sqlite";
import type { ActiveThreadRow } from "../../core/types.js";
import {
  listClaudePids,
  readProcessCwd as defaultReadProcessCwd,
} from "./proc.js";
import { listTmuxPanes, correlatePidToTmux } from "./tmux-panes.js";
import { projectsRoot as defaultProjectsRoot } from "./discover.js";
import { getRecapText } from "../../core/search/recap.js";

const LIVE_THRESHOLD_MS = 60_000;
const IDLE_THRESHOLD_MS = 30 * 60_000;

export interface ScanOpts {
  /** Override Claude Code's projects root. Defaults to projectsRoot() from discover.ts. */
  projectsRoot?: string;
  /** Override the cwd reader. Tests pass an async function returning a fixed cwd. */
  readProcessCwd?: (pid: number) => Promise<string | null>;
}

/**
 * Claude Code encodes a project's cwd by replacing every '/' with '-'. So
 * '/home/shav/work/frontend' becomes '-home-shav-work-frontend'. This is the
 * directory name under ~/.claude/projects/ that contains that project's
 * JSONLs.
 */
export function encodeProjectsDirName(cwd: string): string {
  return cwd.replace(/\//g, "-");
}

interface DbChatMeta {
  conversation_id: string;
  msg_count: number;
  git_branch: string | null;
}

/**
 * Scan currently-running claude processes and produce a row per live or idle
 * thread. Per spec §D5 — process discovery, status classification, tmux
 * correlation, and DB lookup for mapped threads.
 */
export async function scanActiveThreads(
  db: DatabaseSync,
  opts: ScanOpts = {},
): Promise<ActiveThreadRow[]> {
  const root = opts.projectsRoot ?? defaultProjectsRoot();
  const readCwd = opts.readProcessCwd ?? defaultReadProcessCwd;

  const pids = await listClaudePids();
  if (pids.length === 0) return [];

  // Tmux pane set is fetched once; correlation per row is cheap.
  const panes = await listTmuxPanes();

  const out: ActiveThreadRow[] = [];
  for (const pid of pids) {
    const cwd = await readCwd(pid);
    if (!cwd) continue;
    const dir = path.join(root, encodeProjectsDirName(cwd));
    const newest = await newestJsonl(dir);
    if (!newest) continue;

    const ageMs = Date.now() - newest.mtimeMs;
    let status: "live" | "idle" | null = null;
    if (ageMs < LIVE_THRESHOLD_MS) status = "live";
    else if (ageMs < IDLE_THRESHOLD_MS) status = "idle";
    if (status === null) continue;

    const sessionId = path.basename(newest.path).replace(/\.jsonl$/, "");
    const meta = lookupChatMeta(db, sessionId);

    const tmuxMatch = await correlatePidToTmux(pid, panes);

    const projectName = cwd.split("/").pop() || cwd;

    const row: ActiveThreadRow = {
      kind: "active",
      source: "claude",
      pid,
      cwd,
      projectPath: cwd,
      projectName,
      sessionId,
      lastActivityMs: newest.mtimeMs,
      status,
    };
    if (meta) {
      row.chatRowId = meta.conversation_id;
      row.msgCount = meta.msg_count;
      row.gitBranch = meta.git_branch ?? null;
      try {
        const recap = getRecapText(db, meta.conversation_id, "claude");
        if (recap) row.recapText = recap;
      } catch {
        // Recap lookup is best-effort.
      }
    }
    if (tmuxMatch) {
      row.tmuxPaneId = tmuxMatch.paneId;
      row.tmuxWindow = { index: tmuxMatch.windowIndex, name: tmuxMatch.windowName };
    }
    out.push(row);
  }
  return out;
}

async function newestJsonl(dir: string): Promise<{ path: string; mtimeMs: number } | null> {
  let entries: string[];
  try {
    entries = await fs.readdir(dir);
  } catch {
    return null;
  }
  let best: { path: string; mtimeMs: number } | null = null;
  for (const name of entries) {
    if (!name.endsWith(".jsonl")) continue;
    const p = path.join(dir, name);
    try {
      const stat = await fs.stat(p);

      if (!best || mtimeMs > best.mtimeMs) best = { path: p, mtimeMs };

    }
  }
  return best;
}
```

```typescript
import type { DatabaseSync } from "node:sqlite";
import type {
  Args, ResultRow, Selectable, SessionStore, MoreRow,
  ProjectHeader, ActiveThreadRow,
} from "../types.js";
import { recentConversations } from "./recent.js";
import { ftsSearch } from "./fts.js";
import { searchProjects } from "./projects.js";

const HOME_PROJECTS_LIMIT = 30;
const SEARCH_PROJECTS_LIMIT = 100;
const HOME_CHATS_PER_PROJECT = 3;
const MIN_CHATS_ON_NAME_HIT = 3;
const PADDING_LOOKAHEAD = 10;

/**
 * Build a project-grouped Selectable list. Each project's chats are listed
 * inline below its ProjectHeader, with an optional dim MoreRow indicating "Y
 * more" when chats are elided. v0.8.2 adds active-thread injection — see §D5.
 *
 * Spec: docs/superpowers/specs/2026-05-24-multivac-dashboard-design.md §D9 + §D5.
 */
export function buildProjectGroups(
  db: DatabaseSync,
  args: Args,
  sessionStore: SessionStore | null,
  activeThreads: ActiveThreadRow[] = [],
): Selectable[] {
  const query = args.query.trim();
  const isHome = query.length === 0;

  const projects = searchProjects(db, {
    limit: isHome ? HOME_PROJECTS_LIMIT : SEARCH_PROJECTS_LIMIT,
    projectFilter: null,
  });

  const matchingChatsByProject = new Map<string, ResultRow[]>();
  if (!isHome) {
    const matches = ftsSearch(db, { ...args, sessionStore });
    for (const c of matches) {
      let arr = matchingChatsByProject.get(c.projectPath);
      if (!arr) {
        arr = [];
        matchingChatsByProject.set(c.projectPath, arr);
      }
      arr.push(c);
    }
  }

  // Bucket active threads by project path so each project group can pick its own.
  const activeByProject = new Map<string, ActiveThreadRow[]>();
  for (const t of activeThreads) {
    let arr = activeByProject.get(t.projectPath);
    if (!arr) {
      arr = [];
      activeByProject.set(t.projectPath, arr);
    }
    arr.push(t);
  }

  // Identify orphan-cwd threads (their projectPath matches no indexed project).
  const knownProjectPaths = new Set(projects.map((p) => p.projectPath));
  const orphanThreadGroups: Array<[string, ActiveThreadRow[]]> = [];
  for (const [projPath, threads] of activeByProject) {
    if (!knownProjectPaths.has(projPath)) {
      orphanThreadGroups.push([projPath, threads]);
    }
  }

  const out: Selectable[] = [];
  const lowerQuery = query.toLowerCase();

  // Emit synthetic project headers + their active threads at the top.
  for (const [projPath, threads] of orphanThreadGroups) {
    const projectName = threads[0].projectName;
    const lastActivity = Math.max(...threads.map((t) => t.lastActivityMs));
    const synthetic: ProjectHeader = {
      kind: "project",
      projectPath: projPath,
      projectName,
      chatCount: 0,
      lastActivity,
      topChatTitles: [],
    };
    out.push(synthetic);
    out.push(...threads);
  }

  for (const proj of projects) {
    const chats = chatsForProject({
      db, proj, isHome, query, lowerQuery,
      sessionStore,
      matches: matchingChatsByProject.get(proj.projectPath) ?? [],
    });

    const projectThreads = activeByProject.get(proj.projectPath) ?? [];
    const mappedThreads = projectThreads.filter((t) => t.chatRowId !== undefined);
    const unmappedThreads = projectThreads.filter((t) => t.chatRowId === undefined);

    // Build the chat-or-active list: replace each chat row with its mapped active
    // thread if one exists.
    const mappedByChatId = new Map<string, ActiveThreadRow>();
    for (const t of mappedThreads) {
      if (t.chatRowId) mappedByChatId.set(t.chatRowId, t);
    }
    const chatsOrActives: Selectable[] = chats.map((c) => {
      const replacement = mappedByChatId.get(c.sessionId);
      return replacement ?? c;
    });

    if (chatsOrActives.length === 0 && unmappedThreads.length === 0) continue; // hide project

    out.push(proj);
    out.push(...unmappedThreads);
    out.push(...chatsOrActives);

    const shownCount = chatsOrActives.filter((r) => r.kind === "chat" || r.kind === "active").length;
    const remaining = proj.chatCount - shownCount;
    if (remaining > 0) {
      out.push({
        kind: "more",
        projectPath: proj.projectPath,
        remainingCount: remaining,
      } satisfies MoreRow);
    }
  }

  return out;
}

interface ChatsForProjectArgs {
  db: DatabaseSync;
  proj: { projectPath: string; projectName: string };
  isHome: boolean;
  query: string;
  lowerQuery: string;
  sessionStore: SessionStore | null;
  matches: ResultRow[];
}

function chatsForProject(opts: ChatsForProjectArgs): ResultRow[] {
  const { db, proj, isHome, lowerQuery, sessionStore, matches } = opts;
  if (isHome) {
    return recentConversations(db, {
      limit: HOME_CHATS_PER_PROJECT,
      projectFilter: null,
      exactProjectPath: proj.projectPath,
      sessionStore,
    });
  }
  const nameHit = proj.projectPath.toLowerCase().includes(lowerQuery)
    || proj.projectName.toLowerCase().includes(lowerQuery);
  if (!nameHit) {
    return matches;
  }
  if (matches.length >= MIN_CHATS_ON_NAME_HIT) {
    return matches;
  }
  const matchIds = new Set(matches.map((m) => m.sessionId));
  const recent = recentConversations(db, {
    limit: PADDING_LOOKAHEAD,
    projectFilter: null,
    exactProjectPath: proj.projectPath,
    sessionStore,
  });
  const padding = recent
    .filter((r) => !matchIds.has(r.sessionId))
    .slice(0, MIN_CHATS_ON_NAME_HIT - matches.length);
  return [...matches, ...padding];
}
```

```typescript
import { useEffect, useRef, useState, useCallback } from "react";
import type { DatabaseSync } from "node:sqlite";
import type { ActiveThreadRow } from "../../core/types.js";
import { scanActiveThreads } from "../../sources/claude/active.js";

const REFRESH_INTERVAL_MS = 4_000;
const ACTIVITY_BUCKET_MS = 5_000;

interface Opts {
  db: DatabaseSync;
  /** When false (e.g. one-shot CLI path), the hook returns [] and does no work. */
  enabled?: boolean;
}

interface Result {
  threads: ActiveThreadRow[];
  refresh: () => void;
}

/**
 * Deep-equal comparator for ActiveThreadRow[] arrays. Compares the SORTED set
 * of PIDs and, for each PID, the fields that affect rendering: status, tmux
 * assignment, sessionId, chatRowId, and the lastActivityMs ROUNDED to the
 * nearest 5-second bucket (so every-second mtime drift doesn't cause re-renders).
 */
export function activeThreadsEqual(a: ActiveThreadRow[], b: ActiveThreadRow[]): boolean {
  if (a.length !== b.length) return false;
  const byPidA = new Map(a.map((r) => [r.pid, r]));
  const byPidB = new Map(b.map((r) => [r.pid, r]));
  if (byPidA.size !== byPidB.size) return false;
  for (const [pid, ra] of byPidA) {
    const rb = byPidB.get(pid);
    if (!rb) return false;
    if (ra.status !== rb.status) return false;
    if (ra.tmuxPaneId !== rb.tmuxPaneId) return false;
    if (ra.sessionId !== rb.sessionId) return false;
    if (ra.chatRowId !== rb.chatRowId) return false;
    const bucketA = Math.floor(ra.lastActivityMs / ACTIVITY_BUCKET_MS);
    const bucketB = Math.floor(rb.lastActivityMs / ACTIVITY_BUCKET_MS);
    if (bucketA !== bucketB) return false;
  }
  return true;
}

export function useActiveThreads({ db, enabled = true }: Opts): Result {
  const [threads, setThreads] = useState<ActiveThreadRow[]>([]);
  const threadsRef = useRef<ActiveThreadRow[]>([]);
  const inFlight = useRef<boolean>(false);

  const rescan = useCallback(async () => {
    if (inFlight.current) return;
    inFlight.current = true;
    try {
      const next = await scanActiveThreads(db);
      if (!activeThreadsEqual(threadsRef.current, next)) {
        threadsRef.current = next;
        setThreads(next);
      }
    } catch {
      // Scan failures are non-fatal — keep last-known threads.
    } finally {
      inFlight.current = false;
    }
  }, [db]);

  useEffect(() => {
    if (!enabled) return;
    rescan();
    const id = setInterval(rescan, REFRESH_INTERVAL_MS);
    return () => clearInterval(id);
  }, [enabled, rescan]);

  const refresh = useCallback(() => {
    void rescan();
  }, [rescan]);

  return { threads, refresh };
}
```

```typescript
import type { DatabaseSync } from "node:sqlite";
import type { ActiveThreadRow } from "../types.js";
import { pickBox } from "../../tui/lib/box.js";

const W = 70;

interface TurnRow {
  type: "user" | "assistant";
  content: string;
  timestamp: number;
}

export function renderActiveThreadPreview(
  db: DatabaseSync,
  row: ActiveThreadRow,
  useColor: boolean,
): string {
  const box = pickBox(useColor);
  const ageSec = Math.max(0, Math.floor((Date.now() - row.lastActivityMs) / 1000));
  const ageStr = ageSec < 60 ? `${ageSec}s` : ageSec < 3600 ? `${Math.floor(ageSec / 60)}m` : `${Math.floor(ageSec / 3600)}h`;
  const tmuxLine = row.tmuxWindow
    ? `tmux: window ${row.tmuxWindow.index} (${row.tmuxWindow.name}) · PID ${row.pid}`
    : `PID ${row.pid}`;

  const headerLines = [
    `${row.status === "live" ? "🟢 " : "🟡 "}${row.title ?? row.projectName}`,
    `${row.cwd}${row.gitBranch ? ` (${row.gitBranch})` : ""}`,
    tmuxLine,
    `${row.status} · last write ${ageStr} ago`,
  ];

  const out: string[] = [];
  out.push(box.topLeft + box.horizontal.repeat(W - 2) + box.topRight);
  for (const line of headerLines) {
    const padded = line.length > W - 4 ? line.slice(0, W - 4) : line.padEnd(W - 4);
    out.push(box.vertical + " " + padded + " " + box.vertical);
  }
  out.push(box.bottomLeft + box.horizontal.repeat(W - 2) + box.bottomRight);

  // Last 6 turns when chatRowId is known.
  if (row.chatRowId) {
    const turns = db.prepare(
      "SELECT type, content, timestamp FROM messages " +
        "WHERE conversation_id = ? AND source = 'claude' " +
        "AND type IN ('user', 'assistant') " +
        "ORDER BY timestamp DESC LIMIT 6"
    ).all(row.chatRowId) as TurnRow[];
    out.push("");
    out.push("Recent turns:");
    for (const t of turns.reverse()) {
      const arrow = t.type === "user" ? "▶ user" : "◀ assistant";
      const head = (t.content || "").split("\n")[0] ?? "";
      out.push(`${arrow}  ${head.slice(0, W - 16)}`);
    }
  }

  out.push("");
  if (row.tmuxWindow) {
    out.push(`(Enter: switch to tmux:${row.tmuxWindow.index})`);
  } else {
    out.push("(Enter: print PID+cwd to stdout and exit)");
  }
  return out.join("\n");
```

```typescript
  useColor: boolean;
  width: number;

export function usePreview({ db, row, useColor, width }: Opts): string {
  const cache = useRef<Map<string, string>>(new Map());
  const [text, setText] = useState("");

  useEffect(() => {
    cache.current.clear();
  }, [width]);

  useEffect(() => {
    if (!row || row.kind === "more") {
      setText("");
      return;
    }
    let key: string;

    const cached = cache.current.get(key);
    if (cached !== undefined) {
      setText(cached);
      return;
    }
    try {
      let out: string;
      if (row.kind === "chat") {
        out = renderPreview(db, row.sessionId, row.source, useColor);

        out = renderProjectPreview(db, row, useColor);

      setText(out);

      setText(`(preview unavailable: ${msg})`);
```

```typescript
}

export function shellSingleQuote(s: string): string {
  return "'" + String(s).replace(/'/g, "'\\''") + "'";
}

/**
 * Build the tmux new-window argv. When `action` is "newchat" or the row has
 * no sessionId, the inner claude command omits --resume (per v0.8.2 §D10:
 * Ctrl-W on project rows starts a fresh chat).
 */
export function buildTmuxNewWindowCommand(
  row: ResultRow,
  opts: ResumeOpts,
  action: ResumeAction = "resume",
): string[] {
  const savedName = opts.savedName ?? null;
  const nameSource =
    (savedName && savedName.length > 0 && savedName) ||
    (row.projectName && row.projectName.length > 0 && row.projectName) ||
    (row.projectPath && path.basename(row.projectPath)) ||
    "claude";
  const windowName = sanitizeTmuxName(nameSource);
  const cwd = row.projectPath || process.cwd();
  const effectiveAction: ResumeAction = action === "newchat" || row.sessionId === "" ? "newchat" : action;
  const claudeArgs = buildClaudeArgs(effectiveAction, row, savedName);
  const innerCmd = ["claude", ...claudeArgs].map(shellSingleQuote).join(" ");
  return ["new-window", "-n", windowName, "-c", cwd, innerCmd];
}

export function spawnTmuxNewWindow(row: ResultRow, opts: ResumeOpts, action: ResumeAction = "resume"): SpawnResult {
  const tmuxArgs = buildTmuxNewWindowCommand(row, opts, action);
  if (row.projectPath && !isExistingDir(row.projectPath)) {
    process.stderr.write(
      `multivac: project path '${row.projectPath}' is not a directory; ` +
        "tmux new-window will fall back to its own cwd.\n"
    );
  }
  const result = childProc.spawnSync("tmux", tmuxArgs, { stdio: "inherit" });
  if (result.error) {
    if ((result.error as NodeJS.ErrnoException).code === "ENOENT") {
      process.stderr.write(
        "multivac: `tmux` not found on PATH. " +
          "Install tmux or run multivac outside a tmux session.\n"
      );
      return { status: EXIT_ENV };
    }
    process.stderr.write(`multivac: spawning tmux failed: ${result.error.message}\n`);
    return { status: EXIT_INTERNAL };
  }
  return { status: result.status ?? EXIT_INTERNAL };
}
```

```typescript
import { useEffect, useRef } from "react";
import type { DatabaseSync } from "node:sqlite";
import { buildProjectGroups } from "../../core/search/unified.js";
import type { Args, ActiveThreadRow, Selectable, SessionStore } from "../../core/types.js";

interface Opts {
  db: DatabaseSync;
  args: Args;
  query: string;
  sessionStore: SessionStore;
  activeThreads: ActiveThreadRow[];
  onResults: (rows: Selectable[], error?: string) => void;
  onPending: (pending: boolean) => void;
}

export function useSearch({ db, args, query, sessionStore, activeThreads, onResults, onPending }: Opts): void {
  const timer = useRef<NodeJS.Timeout | null>(null);

  useEffect(() => {
    if (timer.current) clearTimeout(timer.current);
    onPending(true);
    timer.current = setTimeout(() => {
      onPending(false);
      try {
        const rows = buildProjectGroups(db, { ...args, query }, sessionStore, activeThreads);
        onResults(rows);
      } catch (e: unknown) {
        const msg = e instanceof Error ? e.message : String(e);
        onResults([], msg);
      }
    }, 80);
    return () => {
      if (timer.current) clearTimeout(timer.current);
    };
  }, [query, activeThreads]); // eslint-disable-line react-hooks/exhaustive-deps
}
```

- **Platform-specific tests skip cleanly** — Linux-only behaviors use `t.skip()` on macOS and vice versa. The full suite must pass on either OS.
- **Active-thread scans are best-effort** — if `pgrep` is not on PATH (rare but possible), `listClaudePids()` returns `[]` and the rest of the pipeline produces no rows. The TUI degrades to its v0.8.1 behavior.
- **Mock at the `__setSpawnCaptureForTests` / `__setReadProcessParentForTests` boundary** — never spawn real subprocesses in unit tests. The fakes are the only place tests interact with the OS.
- **macOS-specific edge** — `lsof -p PID -d cwd -F n` may output diagnostic lines without an `n` prefix (e.g., when the process is gone). `parseLsofCwdOutput` already returns `null` in that case.
- **Tmux pane PPID-chain walk caps at 5 levels** — deeper chains (nested tmux, screen-inside-tmux) produce no match. This is acceptable per spec §D5.
