# Code of Conduct

This project adopts version 2.1 of the **Contributor Covenant** as its Code of Conduct.

The canonical text is published at:

- HTML: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Markdown: https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md

By participating in this project — opening issues, submitting pull requests, commenting, or interacting with maintainers or other contributors — you agree to abide by the linked Code of Conduct.

## Reporting

If you experience or witness a violation, contact the maintainers privately via a direct GitHub message to the repository owner (`@krmrn42`). Reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and safety of the reporter.

## Enforcement

Maintainers follow the enforcement guidelines published with the Contributor Covenant 2.1:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
